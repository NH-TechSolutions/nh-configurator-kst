# KST configurator (Nortek Hendriks)

Standalone product configurator for the KST range (automated 3-piece sanitary ball valve and angle seat valve), prepared by Nortek Hendriks. Single self-contained HTML file: open `index.html` in a browser.

Online: https://nh-techsolutions.github.io/nh-configurator-kst/

Snapshot of 17 October 2026. Preview, not an official KST tool. Technical data comes from the manufacturer's public catalogues; verify before ordering.
